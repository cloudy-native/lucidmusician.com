# Writing Style Guide

This project follows **AP Style with the Oxford comma**. Apply these rules to all content (markdown, page copy, component text).

## Rules

1. **Oxford comma** — Always use the serial comma: "red, white, and blue."
2. **Em-dashes** — Always surround with spaces: "word — word." Never "word—word."
3. **Numbers** — Spell out one through nine. Use numerals for 10 and above. Exceptions: ages, dimensions, percentages, prices, versions.
4. **Percent** — Use "%" with numerals: "50% off." Spell out "percent" only when starting a sentence.
5. **Capitalization after colons** — Capitalize the first word after a colon only if it begins a complete sentence.
6. **Headline/title case** — Use title case for page titles and blog post titles. Use sentence case for section headings within content.
7. **Abbreviations** — Spell out on first use, abbreviate thereafter: "Digital Audio Workstation (DAW)."
8. **Quotes** — Use double quotes for direct quotes. Place commas and periods inside quotation marks.
9. **Lists** — Use a period at the end of bullet items that are complete sentences. No period for fragments.
10. **Times** — Use figures with a.m./p.m.: "9 a.m." not "9am."
